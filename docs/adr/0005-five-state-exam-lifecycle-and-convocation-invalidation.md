# Five-State Exam Lifecycle and Convocation Invalidation

To guarantee official integrity for examinations, we decided to structure exams into five explicit states: `Draft`, `Scheduled`, `Published`, `Completed`, and `Archived`. Modifications made to an exam after reaching `Published` require an explicit Emergency Reschedule confirmation, which automatically invalidates previously issued QR-coded convocations, regenerates updated PDFs, and dispatches urgent alerts via the notification gateway.
