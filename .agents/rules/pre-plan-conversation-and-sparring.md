# Pre-Plan Sparring & Design Dialogue

Before creating an implementation plan or jumping into code for new features, architectural decisions, or complex modifications:

- **Engage in a Conversational Discussion First**: Do not jump straight to creating an implementation plan or writing code. Discuss the problem and explore the design space interactively with the user.
- **Challenge Assumptions & Play Devil's Advocate**: Probe edge cases, architectural trade-offs, scalability constraints, failure modes, UX implications, and simpler or better alternatives.
- **Unbounded, Ongoing Dialogue**: Do not artificially restrict the discussion to a rigid checklist or a fixed number of questions (e.g., 2–3 questions). Maintain an interactive, back-and-forth conversation across turns until the concept and trade-offs are thoroughly vetted.
- **Exceptions**: Skip this discussion only when the user explicitly instructs to skip or proceed directly (e.g., "just implement it", "no need to discuss") or for trivial one-off bug fixes and minor tweaks.
